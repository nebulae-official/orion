01

Primary symbol

mark.primary
The Aperture — hero
Full color
Construction: two concentric rings + three satellite nodes at 0°/120°/240°, with a gradient core and precision halo. The three satellites echo Orion's belt; the rings read as aperture / viewport / dish.
02

Wordmark

wordmark.primary
orion · Space Grotesk
Lowercase
Primary logotype. Space Grotesk, 700, tight tracking (−0.03em), lowercase. Custom kerning: the r–i pair is tightened by 8 units; o–n terminals are optically balanced.
wordmark.caps
ORION · tracked caps
Display
Display variant. Same family, 700, +0.22em tracking, uppercase. Use for signage, slide titles, printed collateral — never inline with body copy.
03

Lockups

lockup.horizontal
Horizontal lockup
Primary
Most-used lockup. Symbol left, wordmark right. Baseline-aligned; clearspace = 1× symbol radius (34px at this scale).
lockup.stacked
Stacked lockup
Secondary
For square formats. Symbol above, wordmark below with optional tagline (tracked 0.3em). Use for social avatars, splash screens, title cards.

App icon · Favicon

App icon squircle
iOS / macOS
Violet tile, white core. For OS launchers where contrast against wallpapers matters. Corner radius 40/180 = 22.2% (Apple squircle).
icon.solid

05

Monochrome variants

mono.white
White on dark
Reverse
For press, single-color print, embroidery. All elements collapse to #EDF1FA; the outer halo ring drops to 50% opacity for hierarchy.
mono.ink
Ink on light
Print
For business cards, letterhead, invoices. Everything #0B0F1A. No gradient — monochrome is monochrome.
06

Clearspace & sizing rules

clearspace
Protect the aperture
Construction
Clearspace = X, where X equals the symbol's outer-ring radius. No text, no UI chrome, no other graphics enter the dotted zone. Minimum sizes: digital symbol 16×16 px, print 8×8 mm; horizontal lockup 96×32 px digital / 20×8 mm print.
07

Misuse

no.stretch
Don't stretch
✕
Never scale on one axis. The aperture must stay circular.
no.recolor
Don't recolor
✕
Never use off-brand colors. Violet → cyan, or monochrome. Nothing else.
no.rotate
Don't rotate
✕
Satellites sit at fixed 0°/120°/240°. Rotating breaks the constellation reference.
