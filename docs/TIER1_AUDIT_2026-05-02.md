## Executive Summary

1. **TTS spec conflict — FishSpeech vs NVIDIA NIM Magpie.** `editor/src/providers/factory.py` routes all TTS through Provider service to `NvidiaNimTTSAdapter` (riva gRPC, Magpie model). `fish_speech.py` is fully implemented but unwired. Decision: align MILESTONE.md to NIM Magpie primary (matches Gishant's NVIDIA-free preference + unifies all providers under the Provider service); keep FishSpeech as offline fallback adapter to be registered in catalog later.

2. **Validator duration bug.** `services/editor/src/video/validator.py:20-21` enforces 55-60s. Spec says 40-55s. Every render currently fails validation. **One-line fix.**

3. **DIRECTOR_AUTO_TRIGGER defaults `false`.** Scout fires TREND_DETECTED, Director silently ignores it without that env var. **One-config fix.**

4. **Provider route layer hardcodes adapters — violates swap rule.** `routes/llm.py:37`, `routes/image.py:32`, `routes/tts.py:32` all instantiate `NvidiaNimXxxAdapter` directly. Adding HuggingFace requires editing these files. Fix = adapter registry lookup (~10 lines per route).

5. **HuggingFace + Pollinations image adapters missing.** Spec lists them as fallbacks. Only NVIDIA NIM image adapter exists.

6. **CONTENT_READY event doesn't exist.** Editor fires `CONTENT_UPDATED`. Rename channel + update Editor.

7. **Dashboard API keys panel is demo UI only.** Server actions (`saveApiKey`, `saveSystemKey`) are properly wired; the visible panel renders static rows. Wire-up only.

8. **Director cost tracking records `provider="ollama"`** at `pipeline.py:245`. Stale string — should be `"nvidia_nim"`.

9. **Object storage gap not in milestone.** Images and audio land in `/tmp/orion/...`. Across Docker containers, Editor cannot read Media's images. Need shared volume or MinIO/S3.

10. **No scene-count enforcement = cost gate missing.** Visual prompter accepts any count. Malformed LLM output → real $$$ image gen calls. Spec calls this out as the cost gate.

## Architecture Findings

### Finding 1: Route files hardcode adapter classes (breaks swap rule)

`services/provider/src/routes/image.py:32`:
```python
adapter = NvidiaNimImageAdapter(entry)
```
Same in `routes/llm.py:37`, `routes/tts.py:32`.

The catalog cleanly separates provider/capability/model. Key resolver is swappable. But routes bypass adapter dispatch and hardcode the class. Adding HuggingFace requires editing route files. Fix: registry lookup `adapter = _IMAGE_ADAPTERS[entry.provider](entry)`. ~10 lines per route.

### Finding 2: Dead Fal.ai key injection in Media

`services/media/src/main.py:59-68` — `_handle_content_created` still calls Identity for `fal_ai` key, sets `request_fal_api_key` contextvar. Provider service client doesn't read that var anymore. Dead block costs an Identity HTTP roundtrip per CONTENT_CREATED event.

### Finding 3: Director cost provider string is "ollama" (stale)

`services/director/src/services/pipeline.py:245`:
```python
cost = CostResult.estimate(provider="ollama", ...)
```
Director uses NVIDIA NIM via Provider service. Cost tracking misattributes every script generation to Ollama.

### Finding 4: TTS provider mismatch vs MILESTONE spec

MILESTONE locked FishSpeech. Code routes through `NvidiaNimTTSAdapter` (riva gRPC, Magpie model). `fish_speech.py` is fully implemented but factory comments it out. **Recommendation:** update MILESTONE to reflect NIM Magpie primary (it's a free NVIDIA provider — matches the strategy you locked) and register FishSpeech as a fallback adapter in catalog.
